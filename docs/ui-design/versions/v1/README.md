# Approved UI version 1.0

Approved by the owner on 2026-10-02 as the first visual and interaction baseline.
Open [index.html](index.html) directly, or serve this directory. These three assets
are an unchanged snapshot of the current draft; SHA-256 checksums are recorded in
[manifest.json](manifest.json). Preserve this directory as an immutable reference.
Future approved visual versions receive their own directory and approval record.

Approval covers the existing visual direction, four views, responsive layout,
component passport and demonstrated entry/replacement interactions. It does not
make synthetic fixture data or browser-side calculations authoritative, approve a
production release, or approve frontend architecture that has not been reviewed.
The working name remains Bike Log; final product naming is still open.

The snapshot shows one lubrication interval. Oil/wax selection, two independent
intervals, disabled/no-chain states, backend persistence, loading/errors and
version conflicts are defined as implementation extensions in the new web spec
and plan; they are not retroactively claimed to appear in this approved snapshot.
The prototype Reset action resets memory only. The connected UI must not offer a
database-reset action. No actual user data, external services or paid assets.
